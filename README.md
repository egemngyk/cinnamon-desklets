
# Egemen's Cinnamon Desklets

A collection of custom desklets built for the **Cinnamon Desktop Environment**.

This repository serves as a central hub for my Cinnamon desklet projects, bringing together tools designed to improve desktop productivity, customization, and everyday usability.

## Projects

Explore the repositories to discover available desklets, their features, installation instructions, and source code.

<!-- PROJECTS_LIST_START -->

### [Desklet Template](https://github.com/egemngyk/desklet-template)

**Version:** `1.0.0`

A clean, modular, and modern starter template for developing Linux Mint Cinnamon desklets with hot-reload theming and boxed settings schema.

### [Weekly Planner](https://github.com/egemngyk/weekly-planner-desklet)

**Version:** `1.2.0`

Multi-instance weekly planner desklet for Cinnamon (Linux Mint) with recurring and date-bound entries, task tracking, and per-instance theming.
